# Hoops Training Week

Weekly basketball training plan with a built-in Tabata timer, points and surprise rewards.

Files to upload to GitHub (all 7, plus this README if you like):
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png

Progress is saved on the iPad only. Parent code: 3883 (change it in Parent settings).
The version shows in the top-right corner, so you can tell when an update has arrived.
